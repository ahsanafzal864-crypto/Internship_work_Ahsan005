## ✨ Features Implemented
* **Drag-and-Drop Zone:** Intuitive file drop area with animated visual indicators for drag states.
* **File Type Validation:** Restricts uploads strictly to image formats (JPG, PNG, GIF) with error alerts for invalid files.
* **Progress Bar Simulation:** Dynamic progress tracking utilizing asynchronous `setTimeout` steps.
* **Image Preview:** Instant rendering of uploaded pictures via the `FileReader` API.
* **Local Persistence (Bonus Challenge):** Saves image data directly into `localStorage` so uploaded previews remain intact after page reload.
* **Delete / Reset Support:** Single-click removal of uploaded files and storage cleanup.

---

## 🛠️ Concepts & Tech Stack
* **HTML5:** Drag and Drop API (`dragover`, `dragleave`, `drop`), File API, `FileReader`
* **CSS3:** Flexbox layout, gradient cards, smooth progress animations
* **JavaScript:** Asynchronous simulation, DOM manipulation, `localStorage`
