# Task 2: Weather App Using API

A dynamic, responsive Weather Application built using HTML, CSS, JavaScript, and the OpenWeatherMap API as part of the **Internee.pk Virtual Internship Program**.

## ✨ Features
* **City Search:** Search weather conditions for any city worldwide.
* **Live Weather Metrics:** Displays temperature (°C), weather conditions, humidity percentage, and wind speed (km/h).
* **Dynamic Background Themes:** Automatically changes the UI background gradient based on the retrieved weather condition (Clear, Rain, Clouds, Snow, etc.).
* **Geolocation Detection:** Built-in current location detection using the Web Geolocation API.
* **Error Handling:** Clear error prompts for invalid city searches or network issues.

---

## 🛠️ Tech Stack & Concepts
* **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
* **API Integration:** OpenWeatherMap API (`fetch()` API & Async/Await)
* **Icons:** Font Awesome
