## ✨ Key Features
* **Step-by-Step Navigation:** Clean division of input sections across multiple intuitive steps.
* **Dynamic Progress Bar:** Visual progress tracking indicator and step circles that update in real-time.
* **Strict Client-Side Validation:** Validates required fields, emails, and URLs before allowing navigation to subsequent steps.
* **Dynamic Review Summary:** Automatically collates all user entries into a formatted review card prior to submission.
* **Autosave with LocalStorage (Bonus Challenge):** Automatically persists input progress and active step state so no data is lost on page reload.
* **Smooth CSS Transitions:** Fluid step animations and interactive field focus states.

---

## 🛠️ Tech Stack & Concepts
* **HTML5:** Semantic form controls, input validation attributes
* **CSS3:** Flexbox, transitions, custom progress bar styling
* **JavaScript:** DOM manipulation, regex validations, `localStorage` API, custom state management
