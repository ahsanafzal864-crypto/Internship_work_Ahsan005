# Task 5: Real-Time Chat App (Frontend Only)

A responsive, feature-packed Real-Time Chat interface built using HTML5, modern CSS3, and JavaScript as part of the **Internee.pk Virtual Internship Program**.

---

## 🌐 Live Demo
* **Live App:** https://internship-work-ahsan005-n8ro.vercel.app/
* **Task Subfolder:** `ChatApp_Task5`

---

## ✨ Features Implemented
* **Instant Message Delivery:** Sends user input instantly to the message container with distinct bubble styles for sent and received chats.
* **Simulated Chatbot with Typing State:** Automated bot responses featuring animated three-dot typing indicators and context replies.
* **Live Timestamps:** Every chat bubble displays the exact delivery timestamp formatted to the minute.
* **Persistent Chat History:** Uses `localStorage` to preserve conversational message threads across page reloads.
* **Clear Conversation Support:** Trash icon to flush stored state and reset chat history.
* **Smooth Auto-Scroll:** Chat feed automatically anchors and scrolls to the newest message.

---

## 🛠️ Tech Stack & Concepts
* **HTML5:** Semantic messaging structure, SVG avatar integration
* **CSS3:** Flexbox layout, bubble animations, custom scrollbars, bouncing typing indicator
* **JavaScript (ES6):** Dynamic DOM injection (`createElement`, `appendChild`), asynchronous response timing (`setTimeout`), `localStorage` API
